on building with ai

I treat coding agents like new teammates: they get the same reviews, the same tests, and the same bar for shipping as everyone else.

In six weeks this spring, my agent pipeline wrote the production code for more than 400 pull requests that I merged into Adobe Firefly's platform. I've merged 787 since April. The model isn't the trick. The scaffolding is: tests that must fail before a fix and pass after it, so a prompt change can't quietly make things worse, and rules that walk agents through the codebase the way a senior engineer would.

I wrote those rules for Adobe's video and Firefly code, taught engineers to use them, and helped teams like Lightroom and Firefly Boards start building this way. On my own team, I'm the senior engineer for 22 software and quality engineers.
