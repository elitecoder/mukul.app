Tools I Built for AI Agents

  • Forgepython

    Forge has 2 agents write competing plans, and critic agents attack both plans. A judge agent merges the best parts into one plan. A fixed series of steps then turns that plan into a code change.

  • ProofGatepython

    ProofGate checks a coding agent's claims that it uploaded, released, or tested code against the commands the agent ran. ProofGate also blocks commands that would delete or damage work. The rules come from 94,000 real commands.

  • Assistantpython

    Assistant starts and tracks my sessions in Claude Code, an AI coding tool. Assistant also answers me on Slack and closes out finished work. Assistant has started 500+ sessions since May 2026.

  • Perchtypescript

    Perch lets you read and reply to your Claude Code sessions from Slack, on any device.

  • debug-modejavascript

    debug-mode makes a coding agent test one guess at a time. The agent adds code that records what happens, reads the record, and then removes that code. debug-mode works on servers, websites, and iOS and Android apps.

  • cmux-session-restorepython

    cmux-session-restore reopens your Claude Code sessions in cmux, a command-line app, after cmux restarts or your Mac restarts.

  • Destiny Ghosttypescript

    Destiny Ghost lets an AI model such as Claude grade, move, and lock your gear in Destiny 2, a video game. I built Destiny Ghost for my own gear after finishing 1,400 raids, the game's hardest group missions.
